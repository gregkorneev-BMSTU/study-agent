# study-agent

Локальный агент для поиска и анализа учебных материалов. На этом этапе репозиторий содержит проектный каркас и архитектурную документацию; индексация, RAG, LLM, MCP-инструменты и UI ещё не реализованы.

## Требования

- Python 3.12 или новее.
- macOS, Windows или Linux. Интерфейс приложения пока не выбран.

## Установка для разработки

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
pytest
ruff check .
```

В Windows используйте `.venv\Scripts\activate`. На компьютере автора найден системный Python 3.9.6; он ниже требуемой версии. Инструкции аудита и установки приведены в [Wiki](wiki/README.md).
