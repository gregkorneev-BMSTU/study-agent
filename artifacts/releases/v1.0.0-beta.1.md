# Study Agent v1 Beta 1

> **Test pre-release for a small study group.** The attached macOS build is ad-hoc signed and has **not** been notarized by Apple. Gatekeeper may block it. A Developer ID signed, notarized installer is planned for a later build.

## Русский

### Что работает

- Нативное приложение macOS на SwiftUI/Xcode для Apple Silicon с фирменной иконкой, системным меню, боковой навигацией и меню в строке состояния.
- Интерфейс переключается между русским и английским; язык сохраняется и передаётся локальной модели для формирования ответа.
- Мастер первого запуска проверяет macOS, процессор, память, свободное место, встроенный Python backend, PDF/OCR runtime, Ollama и установленные модели. Его можно снова открыть из настроек.
- Если Ollama уже установлена, её можно запустить из мастера. Если нет — мастер открывает официальный сайт Ollama для графической установки. Установленные модели определяются через локальный API.
- Qwen 3.5 4B загружается по выбору пользователя через локальную Ollama. Мастер показывает прогресс, который сообщает Ollama, и поддерживает отмену и повторную попытку. Уже установленная модель повторно не загружается автоматически; в настройках можно выбрать и другие установленные модели.
- Библиотека подключает выбранные пользователем папки. Поиск охватывает TXT, Markdown, PDF с цифровым текстом, а при локально готовом Chandra OCR — сканированные PDF и изображения. Найденный исходный файл можно открыть из ответа.
- Ответ формируется локальной моделью Ollama по найденным фрагментам; пользовательские документы не отправляются в облачный сервис. Chandra OCR остаётся необязательным, а распознанный текст кэшируется локально.
- Системные светлая и тёмная темы, настройки контраста и уменьшения движения. Установочный DMG содержит приложение и ярлык Applications в окне Finder с системно адаптивным фоном.

### Установка и ограничения

Требуются **macOS 14 или новее** и **Apple Silicon (arm64)**. Скачайте DMG, откройте его и перетащите `Study Agent.app` в `Applications`, затем запустите приложение. Для ответов нужна локальная Ollama с установленной моделью; простой поиск доступен и без модели. Ollama устанавливается её собственным графическим установщиком, который мастер открывает на официальном сайте.

Это тестовая ad-hoc сборка без Developer ID и нотариализации; обычная установка может быть заблокирована Gatekeeper. Приложение не обходит защиту macOS. Веса Chandra не входят в DMG; их наличие пока нельзя достоверно подтвердить из мастера, а загрузка/установка OCR из приложения не реализована. Упакованное приложение не начинает скрытую загрузку OCR при поиске. DOCX, постоянный индекс/семантический RAG, Universal/Intel и проверенная Windows-сборка пока отсутствуют. Точность OCR и расход ресурсов моделей ещё не измерены на целевых устройствах.

## English

### What works

- Native SwiftUI/Xcode macOS app for Apple Silicon with the Study Agent icon, system app menus, sidebar navigation, and a menu bar item.
- Russian and English interface selection. The preference persists and also guides the language of local model answers.
- First-run setup checks macOS, CPU architecture, memory, free disk space, the bundled Python backend, PDF/OCR runtime, Ollama, and installed models. It can be reopened from Settings.
- Setup can open an existing Ollama app or the official Ollama download page for a graphical installation. Installed models are read through the local API.
- User-initiated Qwen 3.5 4B download through local Ollama, with progress reported by Ollama, cancel, and retry. Installed models are not downloaded again automatically; other installed models remain selectable in Settings.
- Library access to folders selected by the user. Search supports TXT, Markdown, PDFs with a text layer, and scanned PDFs/images when local Chandra OCR is ready. Results can open their original files.
- Local Ollama answers based on retrieved passages. User documents are not sent to a cloud service. Chandra OCR is optional, with a local cache for extracted text.
- System light and dark appearance, contrast and reduced-motion settings. The DMG contains the app and an Applications shortcut in a Finder window using the system appearance.

### Install and known limits

Requires **macOS 14 or later** and **Apple Silicon (arm64)**. Download and open the DMG, drag `Study Agent.app` into `Applications`, then launch it. Local Ollama and an installed model are required for generated answers; basic search is available without a model. Setup opens Ollama's official site and its own graphical installer.

This is an ad-hoc signed test build without Developer ID notarization; Gatekeeper may block a normal launch. Study Agent does not bypass macOS security. Chandra weights are not bundled, setup cannot yet verify them reliably, and in-app OCR weight installation is not available. The packaged app will not silently download OCR weights while searching. DOCX, a persistent index/semantic RAG, Universal/Intel builds, and a verified Windows build are not available yet. OCR quality and model resource usage have not been measured on target devices.
