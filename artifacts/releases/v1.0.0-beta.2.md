# Study Agent v1 Beta 2

> **Pre-release for a small study group.** This macOS build is ad-hoc signed and has not been notarized by Apple. Gatekeeper may block it. Requires macOS 14 or later on Apple Silicon (arm64).

## Русский

### Что нового в Beta 2

- Установка Chandra OCR из мастера «Компоненты и диагностика»: загрузка закреплённой версии модели в локальные данные приложения, показ прогресса, отмена и повторная попытка. Перед установкой требуется не менее 12 ГБ свободного места. Веса модели (около 10,6 ГБ) не входят в DMG; ознакомьтесь с [лицензией modified OpenRAIL-M](https://huggingface.co/datalab-to/chandra-ocr-2/blob/af93b47dba1b47b6640c86ccf487ed2260ab9a09/LICENSE) до загрузки или использования модели.
- Пустое состояние библиотеки выровнено по центру свободной области страницы.
- Номер сборки macOS-приложения увеличен до 2.

### Функции приложения

- Нативное приложение macOS на SwiftUI/Xcode с фирменной иконкой, системным меню, боковой навигацией, настройками, системным выбором папок и menu bar.
- Русский и английский интерфейс; выбор языка сохраняется. Язык передаётся локальной модели для формирования ответа.
- Мастер первого запуска проверяет macOS, архитектуру, память, свободное место, встроенный backend, PDF/OCR runtime, Ollama и установленные модели. Диагностику можно открыть повторно из настроек.
- Мастер может запустить уже установленную Ollama или открыть её официальный сайт. Для ответов требуется запущенная Ollama с локальной моделью; Qwen 3.5 4B можно загрузить по запросу с прогрессом, отменой и повторной попыткой. В настройках можно выбрать другую установленную модель.
- Библиотека подключает выбранные папки. Поиск поддерживает TXT, Markdown, PDF с текстовым слоем и, после установки модели Chandra, сканированные PDF и изображения. Результат открывает исходный файл.
- Ответы формируются локальной Ollama по найденным выдержкам. Поиск и OCR выполняются на Mac; пользовательские документы не отправляются в облачный сервис.
- Светлая и тёмная темы, русский и английский языки, параметры повышенного контраста и уменьшения движения.
- Установочный DMG содержит приложение и ярлык Applications в окне Finder с системно адаптивным фоном.

### Установка и ограничения

Скачайте DMG, откройте его и перетащите `Study Agent.app` в `Applications`. Затем запустите приложение и пройдите настройку. Для обычного поиска установите папку с материалами; для генерации ответов нужна Ollama и локальная модель. Chandra OCR загружается отдельно только по действию пользователя.

Сборка ad-hoc подписана, но не имеет Developer ID и не нотариализована Apple. Gatekeeper может блокировать запуск. Приложение не обходит защиту macOS. Веса Chandra скачиваются из Hugging Face и не включены в DMG; ознакомьтесь с [лицензией modified OpenRAIL-M](https://huggingface.co/datalab-to/chandra-ocr-2/blob/af93b47dba1b47b6640c86ccf487ed2260ab9a09/LICENSE) до загрузки или использования модели. Качество OCR и расход ресурсов модели на целевых Mac не измерялись. DOCX, постоянный индекс и семантический RAG, Intel/Universal сборки и проверенная Windows-сборка пока не доступны.

## English

### What’s new in Beta 2

- Install Chandra OCR from **Components and Diagnostics**: download a pinned model revision to local app data, with progress, cancel, and retry. At least 12 GB of free disk space is required. Model weights (about 10.6 GB) are not included in the DMG; review the [modified OpenRAIL-M license](https://huggingface.co/datalab-to/chandra-ocr-2/blob/af93b47dba1b47b6640c86ccf487ed2260ab9a09/LICENSE) before downloading or using the model.
- Centered the Library empty state within the page’s available content area.
- Increased the macOS app build number to 2.

### App features

- Native SwiftUI/Xcode macOS app with the Study Agent icon, system menus, sidebar navigation, Settings, system folder picker, and a menu bar item.
- Russian and English interface with a saved language preference. The selected language is passed to the local model for answers.
- First-run setup checks macOS, architecture, memory, free disk space, the bundled backend, PDF/OCR runtime, Ollama, and installed models. Diagnostics can be reopened from Settings.
- Setup can launch an existing Ollama installation or open its official website. Answer generation requires Ollama and a local model. Qwen 3.5 4B can be downloaded on request with progress, cancel, and retry; another installed model can be selected in Settings.
- Library access to user-selected folders. Search supports TXT, Markdown, text-layer PDFs, and scanned PDFs/images after Chandra is installed. Results can open their source files.
- Answers are generated locally by Ollama from retrieved passages. Search and OCR run on the Mac; user documents are not sent to a cloud service.
- Light and dark appearances, Russian and English, increased contrast, and reduced motion.
- The installer DMG contains the app and an Applications shortcut in a Finder window that follows system appearance.

### Install and known limits

Download and open the DMG, then drag `Study Agent.app` to `Applications`. Launch the app and complete setup. Add a folder to search its contents; generated answers require Ollama and a local model. Chandra OCR is downloaded separately only after the user requests it.

This ad-hoc signed build does not have a Developer ID signature and has not been notarized by Apple. Gatekeeper may block it. Study Agent does not bypass macOS security. Chandra weights are downloaded from Hugging Face and are not bundled; review the [modified OpenRAIL-M license](https://huggingface.co/datalab-to/chandra-ocr-2/blob/af93b47dba1b47b6640c86ccf487ed2260ab9a09/LICENSE) before downloading or using the model. OCR quality and resource usage have not been measured on target Macs. DOCX, a persistent index and semantic RAG, Intel/Universal builds, and a verified Windows build are not available yet.
