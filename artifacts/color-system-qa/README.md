# QA цветовой системы

Снимки получены на macOS Cocoa при 1240×820; компактный экран настроек — 760×560. QA использовал изолированное временное хранилище `QSettings`, пустую библиотеку и синтетические состояния приложения. Личные папки не добавлялись и не сканировались.

В заголовке боковой панели отображается фирменная иконка из Apple Icon Kit, как при запуске из исходников, так и в bundle приложения.

## Контраст и состояния

`pytest` проверяет формулу контрастности WCAG для обычного текста и состояний на основных поверхностях. Полученные коэффициенты для частых пар:

| Пара | Контраст |
| --- | ---: |
| Светлый secondary `#60758F` / фон `#F7FAFF` | 4.52:1 |
| Тёмный secondary `#A8BBD1` / фон `#101C2E` | 8.71:1 |
| Белый текст / primary `#0B65F2` | 5.05:1 |
| Белый текст / hover `#095BD9` | 5.72:1 |
| Тёмный focus `#6FB7FF` / карточка `#1B2B43` | 6.72:1 |
| Светлый control border `#60758F` / белое поле | 4.73:1 |

Успех, предупреждение, ошибка и ожидание проверяются на фоне окна и карточки. Светлый и тёмный варианты семантических меток соответствуют 4.5:1. Цветовая схема формируется одинаковым stylesheet для навигации, поиска, библиотеки, настроек, контролов, карточек, меню, подсказок и прогресс-бара. Прогресс-бар и индексатор ещё отсутствуют как функциональные компоненты; новый UI для них не добавлялся.

## Что проверено

- Отрисованы поиск, библиотека и настройки в светлой и тёмной темах на Cocoa.
- Отрисованы синтетический результат с длинным именем и ответ модели; полный заголовок доступен в tooltip.
- Проверен поддерживаемый минимальный размер окна 760×560.
- Unit-тесты рассчитывают контраст текста, семантических статусов, selection, кнопок, focus и границ полей.
- Pytest проверяет токены палитры, fallback прозрачности, режим высокого контраста и стили интерактивных состояний.
- Поведение поиска, навигации и настроек в исходниках не менялось; статусы получили только семантическое оформление.

Снимки проверены визуально. VoiceOver, Windows и системные настройки доступности ОС не проверялись в этом изменении. Тестирование кадровой частоты не выполнялось; новые blur, градиенты и GPU-эффекты не вводились.
