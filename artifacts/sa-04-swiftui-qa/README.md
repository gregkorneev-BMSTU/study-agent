# SA-04 SwiftUI QA

## Проверено

- Xcode `.app` запускалась в отдельной копии с отдельным bundle ID, а выбранная папка содержала только синтетические файлы в `/tmp`.
- В библиотеке проверены пустое состояние и строка источника со статистикой `2 documents · 3 passages` и итогом `Index up to date`.
- Через тестовый JSON Lines bridge проверены поисковые карточки с разными страницами PDF и раздел «Sources Used» с двумя источниками, соответствующими hits, переданным команде `answer`.
- Python индексатор и bridge дополнительно проверены тестами, а Swift queue/DTO harness проверяет progress events, повтор после ошибки и уникальную identity фрагментов.

## Ограничения визуального QA

Окна приложения осмотрены через CUA screenshot/accessibility API, но доступный screenshot API возвращает изображение только для просмотра в сессии и не предоставляет сохранение в репозиторий. Поэтому в эту папку не добавлены бинарные скриншоты и не сделаны искусственные изображения. Полноразмерные снимки для светлой/тёмной темы, состояния progress/cancel, warning и поиска остаются ручным QA пунктом.

Экранный сценарий использовал тестовый bridge с синтетическими ответами для проверки отображения источников. Он не заменяет сквозную ручную проверку упакованного production backend на реальных разрешённых материалах. См. точные результаты и непроверенные сценарии в [testing.md](../../wiki/testing.md).
