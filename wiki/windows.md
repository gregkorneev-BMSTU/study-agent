# Study Agent для Windows

## Статус

Windows-версия Study Agent находится в разработке в рамках Issue #5 (SA-05).

Проверена локальная тестовая сборка 1.0.7.0 для Windows x64.
Она не является официальным публичным релизом.

Нативный интерфейс построен на WinUI 3, а Python-backend
упакован с помощью PyInstaller и включён в MSIX.

## Установка

Для локального тестирования используется пакет
`StudyAgent-Windows-1.0.7-x64.msix`.

Перед установкой необходимо доверять сертификату, которым
подписан MSIX. Текущая тестовая сборка подписана сертификатом
`CN=AppPublisher`.

Сертификат является тестовым и не предназначен для публичного
распространения. Обычная установка на другом компьютере
без настройки доверия к сертификату не подтверждена.

После установки приложение запускается из меню «Пуск».
Устанавливать Python, pip и отдельные зависимости Python
пользователю не требуется: backend включён в пакет.

Установка на чистой Windows 10/11 без Python пока не проверена.

## Работа с учебными материалами

1. Откройте раздел «Библиотека».
2. Нажмите «Добавить папку».
3. Выберите папку с учебными документами.
4. Перейдите в раздел «Поиск».
5. Введите поисковый запрос.
6. Просмотрите найденные документы и выдержки.

Поиск работает без Ollama.

В локальных тестах подтверждены TXT-файлы, в том числе
с кириллическими названиями и путями.

## Генерация ответов

Для генерации необходимы:

- установленная и запущенная Ollama;
- хотя бы одна установленная локальная модель;
- результаты поиска по подключённым документам.

Пользователь устанавливает Ollama отдельно:
https://ollama.com/download/windows

На тестовой машине проверена модель `qwen3:1.7b`.

На странице поиска нажмите «Обновить модели», выберите модель,
выполните поиск и нажмите «Сгенерировать ответ».

Если Ollama недоступна, приложение показывает сообщение
об ошибке подключения. Поиск документов остаётся доступным.

Модели Ollama не входят в MSIX.

## Возможности и ограничения

- Интерфейс поддерживает русский и английский языки.
- Доступны системная, светлая и тёмная темы.
- Подключённые папки и настройки сохраняются после перезапуска.
- PDF с текстовым слоем поддерживается backend.
- Извлечение текста из сканированных PDF требует OCR.
- В тестовой Windows-сборке OCR runtime отсутствует.
- Извлечение текста из цифрового PDF и поиск по нему подтверждены ручным тестом в WinUI после обновления backend.
- Индексирование TXT и цифрового PDF, а также поиск по содержимому подтверждены в обновлённой тестовой версии WinUI.
- Обработка DOCX покрыта Python-тестами, но ручная проверка DOCX в Windows UI не проводилась.
- Семантический поиск не подтверждён.
- Наличие или запуск на Windows 10, разных DPI и с экранным
  диктором пока не подтверждены.

## Подпись и безопасность

Тестовый MSIX 1.0.7.0 имеет цифровую подпись со статусом Valid
на машине тестирования, подписант — CN=AppPublisher.

Это не означает наличие коммерческого сертификата,
публичного доверия или успешного прохождения SmartScreen.

Не публикуйте приватный ключ, PFX, пароли подписи,
личные документы, модели и пользовательские данные.

## Результаты ручного smoke-тестирования

Дата проверки: 25 октября 2026 года.

Среда: Windows x64, установленный MSIX 1.0.7.0.

Подтверждено:

- пакет установлен в обычном режиме MSIX;
- встроенный StudyAgentBackend.exe найден в каталоге пакета;
- цифровая подпись локального MSIX имеет статус Valid;
- поиск по TXT-документам работает;
- ответы через локальную Ollama и qwen3:1.7b генерируются;
- ссылки на найденные источники присутствуют в ответах;
- при остановке Ollama приложение не завершается аварийно;
- после запуска Ollama обнаружение модели и генерация восстановились;
- кириллические пути и названия TXT-файлов обрабатываются;
- две подключённые папки сохраняются после перезапуска;
- переключение русского и английского интерфейса работает;
- выбранная тёмная тема сохраняется.

Не проверено:

- установка на чистой Windows без Python;
- Windows 10 и несколько режимов DPI;
- полный keyboard-only и accessibility smoke-тест;
- OCR на реальных сканах;
- публичное распространение подписанного пакета.

- Python: 73 теста пройдены, 1 POSIX-only тест пропущен на Windows.
- Ruff и actionlint: проверка пройдена.
- GitHub Actions для PR #13: все четыре задания прошли (Python 3.12/3.13, macOS, Windows).
- WinUI 3 успешно собирается под win-x64.
- Обновлённый PyInstaller backend успешно собран и возвращает корректные ответы диагностики, индексирования и поиска.
- Поиск по русским словам в двух TXT-файлах и в цифровом PDF проверен через обновлённое WinUI-приложение.

Указанные проверки обновлённого кода выполнены на машине разработки, а не на чистой Windows.
Ранее установленный тестовый MSIX 1.0.7.0 не следует считать повторно проверенным с новым backend.
Ручные тесты DPI, клавиатурной доступности и установки на чистой Windows по-прежнему не проведены.
OCR для сканов отсутствует.

## Разработка

Для сборки Python-backend в подготовленной среде:

```powershell
.\scripts\build_windows_backend.ps1
```

Для проверки WinUI 3:

```powershell
dotnet build .\windows\StudyAgent.Windows\StudyAgent.Windows.csproj -c Debug -r win-x64 -p:Platform=x64
```

Сам MSIX собирается через `winapp package`.
Для Release-пакета необходима корректная конфигурация
подписи и доступный собранный Python-backend.

Работа ведётся в ветке `feature/sa-05-windows`.
Публичный выпуск требует отдельного решения команды проекта.
