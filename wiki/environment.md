## Совместимость кандидатов

| Кандидат | Оценка для машины и основы | Ограничение/проверка |
|---|---|---|
| Python | 3.12+ указан в проекте; системный 3.9.6 не используем | Современные MCP/LangChain требуют минимум Python 3.10; поддержка версий должна проверяться при добавлении конкретных зависимостей |
| Ollama + Qwen3 4B | Совместимы с Apple Silicon; 4B — начальный кандидат для замера | Примерно 2.6 ГБ для Q4 весов; контекст и KV cache увеличат расход общей памяти |
| Qwen3 8B | Возможно проверить локально, но не выбирать по размеру файла | Примерно 5.2 ГБ Q4 веса; полноценная нагрузка с контекстом и приложением требует измерения |
| Локальные эмбеддинги | Совместимы концептуально; кандидат Qwen3 embedding 0.6B около 639 МБ | Проверить качество на русских учебных запросах, лицензию, скорость и совместный расход памяти |
| Chroma | Правдоподобный локальный вариант для корпуса 10–100 документов | Проверить persistence, упаковку, стабильность установки на macOS/Windows/Linux; не установлена |
| LangGraph | Технически возможен, но не нужен для текущего каркаса | Добавлять только если подтверждённая логика ветвления/состояния превышает простой маршрутизатор |
| MCP Python SDK / FastMCP | Реализуемо при Python >=3.10 | Совместимость API, transport и граница доверия инструментов проверяются при реализации |
| PySide6 или React + API | Оба пути возможны, UI не выбран | React добавляет Node-процесс и упаковку; PySide6 требует нативного дистрибутива и проверки платформ |

Оценки размеров модели — размер опубликованных Q4 артефактов, не полное использование RAM. Оценки являются основанием для будущего benchmark, не решением о стеке. Все запуски LLM должны оставаться локальными по умолчанию.
