# Локальный OCR Chandra

## Реализация

`LocalFolderSource` поддерживает `.pdf`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.tif`, `.tiff` и `.bmp` вместе с `.txt`/`.md`. PDFium (лёгкая базовая зависимость) извлекает текстовый слой PDF. Страница, где найдено меньше 32 буквенно-цифровых символов, передаётся Chandra; изображения всегда проходят OCR. Для распознавания используется официальный Python API `InferenceManager(method="hf")` и `ocr_layout`. Удалённый vLLM/API режим не вызывается.

Распознанный результат сохраняется вне папки источника и репозитория, в системном каталоге пользовательского кэша. Ключ строится по SHA-256 содержимого, поэтому изменённый файл обрабатывается заново. В PDF-результате сохраняются заголовки `Page N`. Оригиналы не изменяются. Chandra и модель загружаются лениво при первом скане/изображении, чтобы не замедлять запуск приложения и чтение обычных текстовых файлов.

Установить OCR-зависимости в окружение разработки:

```sh
python -m pip install '.[ocr]'
```

В окружении разработки поиск по выбранной папке с изображениями или сканированным PDF запускает локальный Hugging Face режим Chandra. Веса могут загрузиться при первом распознавании в окружении разработки. В упакованном macOS `.app` сетевые загрузки весов при поиске отключены: без уже имеющихся локальных весов OCR сообщает, что модель недоступна. Код не загружает модель во время сборки, тестов или при чтении текстового PDF. Для нативного `.app` helper собирают из окружения с `.[packaging,ocr]`; веса в `.app`, DMG и Git не включены.

Цифровые PDF доступны и без OCR-группы. Если OCR runtime или веса недоступны в упакованном приложении, сканированная страница либо изображение завершается сообщением о недоступности OCR; графическая установка весов пока не реализована. Мастер первого запуска показывает OCR как необязательный компонент и не объявляет веса установленными без проверки. Быстрые тесты подменяют PDF renderer/OCR и не скачивают и не запускают модель.

## Лицензии и границы

- Код Chandra опубликован под Apache 2.0.
- Для весов в репозитории есть отдельный изменённый OpenRAIL-M текст. Он включает ограничения использования, атрибуцию и условия распространения. В приложении веса не поставляются и третьим лицам не раздаются: каждый участник учебного проекта ставит и загружает их в своём окружении. Лицензия содержит исключение для personal use/research из порогов выручки и финансирования; остальные условия продолжают действовать.
- README Chandra отдельно указывает требование лицензии для коммерческого self-hosting. Это не заменяет проверку условий модели при изменении способа использования или распространения.
- Не подключать облачный Datalab API как fallback. Документы передаются только локальному процессу Chandra.

Исходники и тексты лицензий: [Chandra](https://github.com/datalab-to/chandra), [код LICENSE](https://github.com/datalab-to/chandra/blob/master/LICENSE), [MODEL_LICENSE](https://github.com/datalab-to/chandra/blob/master/MODEL_LICENSE).

## Не проверено

Модель не загружалась в рамках реализации. Не проведены измерения времени/памяти, а также проверка точности на русской печати, рукописи, формулах и таблицах на Apple Silicon и Windows. Порог 32 символа — первичное эвристическое решение, его нужно калибровать на разрешённой тестовой выборке. Ссылки на страницы пока присутствуют в извлечённом Markdown, но UI поиска ещё не показывает номер страницы как отдельное поле.
