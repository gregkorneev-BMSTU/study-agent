# Локальный OCR Chandra

## Реализация

`LocalFolderSource` поддерживает `.pdf`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.tif`, `.tiff` и `.bmp` вместе с `.txt`/`.md`. PDFium (лёгкая базовая зависимость) извлекает текстовый слой PDF. Страница, где найдено меньше 32 буквенно-цифровых символов, передаётся Chandra; изображения всегда проходят OCR. Для распознавания используется официальный Python API `InferenceManager(method="hf")` и `ocr_layout`. Удалённый vLLM/API режим не вызывается.

Распознанный результат сохраняется вне папки источника и репозитория, в системном каталоге пользовательского кэша. Ключ строится по SHA-256 содержимого, поэтому изменённый файл обрабатывается заново. В PDF-результате сохраняются заголовки `Page N`. Оригиналы не изменяются. Chandra и модель загружаются лениво при первом скане/изображении, чтобы не замедлять запуск приложения и чтение обычных текстовых файлов.

Установить OCR-зависимости в окружение разработки:

```sh
python -m pip install '.[ocr]'
```

В окружении разработки поиск по выбранной папке с изображениями или сканированным PDF запускает локальный Hugging Face режим Chandra. В упакованном macOS `.app` автоматическая загрузка при поиске отключена. Пользователь может явно установить Chandra из мастера «Компоненты и диагностика»: приложение скачивает snapshot модели `datalab-to/chandra-ocr-2` (10,6 ГБ) с Hugging Face и показывает прогресс/отмену. Файлы сохраняются в `~/Library/Application Support/Study Agent/Models/Chandra`; повторная загрузка продолжает частичный snapshot. Тег модели закреплён на revision `af93b47dba1b47b6640c86ccf487ed2260ab9a09`. Пользовательские документы в загрузчик не передаются.

Цифровые PDF доступны и без OCR-группы. Если OCR runtime отсутствует, приложение просит переустановить сборку; если runtime есть, но модель не установлена, настройки показывают кнопку установки. Диагностика проверяет marker, `config.json` и веса локально без запуска модели и без сети. Отмена загрузки останавливает helper; повторный запуск Hugging Face продолжает незаконченные файлы. OCR при распознавании остаётся offline-only в упакованном приложении. Быстрые тесты подменяют PDF renderer/OCR и загрузчик; сеть и модель не запускаются.

## Лицензии и границы

- Код Chandra опубликован под Apache 2.0.
- Для весов модели есть отдельная лицензия OpenRAIL-M. Приложение не включает и не распространяет веса: каждый пользователь явно скачивает их на свой компьютер. Перед установкой из приложения доступна ссылка на лицензию закреплённой ревизии. Для некоммерческого учебного использования всё равно следует соблюдать остальные условия лицензии.
- README Chandra отдельно указывает требование лицензии для коммерческого self-hosting. Это не заменяет проверку условий модели при изменении способа использования или распространения.
- Не подключать облачный Datalab API как fallback. Документы передаются только локальному процессу Chandra.

Исходники и тексты лицензий: [Chandra](https://github.com/datalab-to/chandra), [закреплённая модель и её LICENSE](https://huggingface.co/datalab-to/chandra-ocr-2/tree/af93b47dba1b47b6640c86ccf487ed2260ab9a09), [исходная лицензия проекта](https://github.com/datalab-to/chandra/blob/master/MODEL_LICENSE).

## Не проверено

Модель не загружалась и не запускалась в рамках реализации. Не проведены измерения времени/памяти, а также проверка точности на русской печати, рукописи, формулах и таблицах на Apple Silicon и Windows. Порог 32 символа — первичное эвристическое решение, его нужно калибровать на разрешённой тестовой выборке. Ссылки на страницы пока присутствуют в извлечённом Markdown, но UI поиска ещё не показывает номер страницы как отдельное поле.
