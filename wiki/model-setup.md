# Установка локальной Qwen

Эта инструкция устанавливает локальную модель для экспериментов. Для разработки RAG на машине автора (Apple M4 Pro, 24 ГБ общей памяти) рекомендация — `qwen3.5:9b` через Ollama: я бы начал с более крупной модели, чтобы проверить качество синтеза нескольких найденных фрагментов. Это обоснованная гипотеза по размеру модели, но не результат benchmark на материалах проекта.

Для широкого круга компьютеров в будущем приложении стоит оставить `qwen3.5:4b` как более лёгкий вариант. Оба размера доступны в Ollama на macOS и Windows. 9B занимает около 6.6–7.6 ГБ на диске, 4B — около 3.3–4.0 ГБ. Во время генерации потребуется дополнительная память; длинный контекст увеличивает расход. Размер загрузки не равен полному расходу RAM, а минимальные требования ещё не измерены. Во время первых тестов не запускайте OCR и Qwen одновременно; сначала оцените каждую модель отдельно.

## 1. Установить Ollama

### macOS

1. Скачайте и установите приложение с [официальной страницы Ollama для macOS](https://ollama.com/download). Официальный пакет требует macOS 14 Sonoma или новее.
2. Откройте Ollama после установки.
3. Запустите Terminal и проверьте CLI:

```sh
ollama --version
```

### Windows

1. Скачайте и запустите `OllamaSetup.exe` с [официальной страницы Ollama для Windows](https://ollama.com/download/windows). Установщик поддерживает Windows 10 или новее.
2. Откройте PowerShell и проверьте CLI:

```powershell
ollama --version
```

Если терминал был открыт до установки и команда не находится, закройте его и откройте заново.

## 2. Скачать Qwen

Выберите размер под компьютер:

- Для прототипирования на машине с 24 ГБ общей памяти — `qwen3.5:9b`.
- Для более ограниченных устройств — `qwen3.5:4b`.

Выполните команды в macOS Terminal или Windows PowerShell. Пример для более лёгкого варианта:

```sh
ollama pull qwen3.5:4b
ollama list
```

Для рекомендации на машине с 24 ГБ можно вместо `qwen3.5:4b` скачать `qwen3.5:9b`:

```sh
ollama pull qwen3.5:9b
ollama list
```

`pull` загружает модель в хранилище Ollama, а не в папку проекта. Загрузка требует интернета и нескольких гигабайт свободного места. Она выполняется один раз, пока модель не удалена.

## 3. Проверить локальный запуск

```sh
ollama run qwen3.5:4b
```

Для проверки большего варианта запустите `ollama run qwen3.5:9b`.

Введите, например:

```text
Ответь по-русски: объясни разницу между компилятором и интерпретатором в двух предложениях.
```

Для выхода из интерактивного режима нажмите `Ctrl+D` в macOS/Linux или `Ctrl+C` в Windows.

## Работа без сети и связь с приложением

`qwen3.5:4b` и `qwen3.5:9b` — локальные модели Ollama; не добавляйте суффикс `:cloud`. Интернет нужен для установки Ollama и первоначальной загрузки выбранной модели. После загрузки локальный запуск соответствующего тега не требует облачной модели.

Установка модели сама по себе **не включает Qwen в Study Agent**: интеграция приложения с Ollama ещё не реализована. Кроме того, для RAG нужна отдельная локальная модель эмбеддингов — Qwen для генерации ответов её не заменяет.

Чтобы выбрать другой размер после проверки оборудования, используйте опубликованный список тегов [Qwen3.5 в Ollama](https://ollama.com/library/qwen3.5). Например, `qwen3.5:2b` меньше, а `qwen3.5:9b` — качественный кандидат для более мощных систем; качество и расход ресурсов нужно сравнить на целевых устройствах.

В RAG модель получает только отобранные поиском фрагменты. Поэтому не нужно задавать ей максимальный контекст ради загрузки целого учебника: сначала важнее проверить качество поиска, разбивки и источников, а затем подобрать ограниченный контекст и замерить общую память.
