# Установка локальной Qwen

Эта инструкция устанавливает локальную модель для экспериментов. Текущий стартовый кандидат — `qwen3.5:4b` через Ollama: одна команда установки модели подходит для macOS и Windows. Это пока не обязательная зависимость приложения и не окончательный выбор для дистрибутива.

Модель занимает примерно 3.3–4.0 ГБ на диске в зависимости от опубликованного набора файлов. Во время генерации потребуется дополнительная память; длинный контекст и изображения увеличивают расход. Размер загрузки не равен полному расходу RAM.

## 1. Установить Ollama

### macOS

1. Скачайте и установите приложение с [официальной страницы Ollama для macOS](https://ollama.com/download). Официальный пакет требует macOS 14 Sonoma или новее.
2. Откройте Ollama после установки.
3. Запустите Terminal и проверьте CLI:

```sh
ollama --version
```

### Windows

1. Скачайте и запустите `OllamaSetup.exe` с [официальной страницы Ollama для Windows](https://ollama.com/download/windows). Установщик поддерживает Windows 10 или новее.
2. Откройте PowerShell и проверьте CLI:

```powershell
ollama --version
```

Если терминал был открыт до установки и команда не находится, закройте его и откройте заново.

## 2. Скачать Qwen

Одинаковые команды в macOS Terminal и Windows PowerShell:

```sh
ollama pull qwen3.5:4b
ollama list
```

`pull` загружает модель в хранилище Ollama, а не в папку проекта. Загрузка требует интернета и нескольких гигабайт свободного места. Она выполняется один раз, пока модель не удалена.

## 3. Проверить локальный запуск

```sh
ollama run qwen3.5:4b
```

Введите, например:

```text
Ответь по-русски: объясни разницу между компилятором и интерпретатором в двух предложениях.
```

Для выхода из интерактивного режима нажмите `Ctrl+D` в macOS/Linux или `Ctrl+C` в Windows.

## Работа без сети и связь с приложением

`qwen3.5:4b` — локальная модель Ollama; не добавляйте суффикс `:cloud`. Интернет нужен для установки Ollama и первоначальной загрузки модели. После загрузки локальный запуск `ollama run qwen3.5:4b` не требует облачной модели.

Установка модели сама по себе **не включает Qwen в Study Agent**: интеграция приложения с Ollama ещё не реализована. Кроме того, для RAG нужна отдельная локальная модель эмбеддингов — Qwen для генерации ответов её не заменяет.

Чтобы выбрать другой размер после проверки оборудования, используйте опубликованный список тегов [Qwen3.5 в Ollama](https://ollama.com/library/qwen3.5). Например, `qwen3.5:2b` занимает меньше места, а `qwen3.5:9b` — больше; качество и расход ресурсов нужно сравнить на целевых устройствах.
