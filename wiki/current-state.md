# Текущее состояние

Состояние на 2026-10-24. Целевая спецификация расширена до кроссплатформенного настольного приложения с локальным OCR, RAG и распространением через GitHub. Фактическая реализация пока остаётся начальным каркасом.

Для **v1 Beta 1** в нативный macOS UI добавлен мастер первого запуска: диагностика Mac, встроенного helper, Ollama и установленных моделей; переход к официальной установке Ollama; загрузка Qwen 3.5 4B через локальный API с реальным прогрессом и отменой; повторная диагностика из настроек. DMG собирается отдельным скриптом с системно адаптивным окном Finder. Версия Xcode — 1.0.0 (build 1), но без Developer ID на машине автора доступна только ad-hoc тестовая сборка. Подробности и границы — в [инструкции по выпуску](macos-release.md).

Нативное macOS-приложение на SwiftUI/Xcode использует упакованный JSON Lines helper для Python-сервисов; PySide6 UI оставлен для Windows-разработки и совместимости. После обнаружения пустого главного окна `NavigationSplitView` заменён на `HSplitView`: визуально проверены поиск, библиотека, настройки и статус Ollama. PNG логотипа загружается напрямую из ресурсов `.app`, а системный `.icns` остаётся иконкой приложения. Проверены Release build, подпись, доступность контролов и результат поиска без подключённых источников. VoiceOver, клавиатурные сценарии и производительность отдельно не проверялись.

README показывает скриншоты текущего нативного UI из Release-сборки с синей иконкой Study Agent. Они заменили прежние PySide6-превью для macOS.

## Готово

- Добавлен Xcode-проект нативного macOS-приложения на SwiftUI с системным окном и боковой навигацией на `HSplitView`, стандартными меню/клавиатурными командами, Settings scene, выбором папок через системный импортёр, SF Symbols, фирменным логотипом, иконкой `.icns` и MenuBarExtra. Окно можно повторно открыть из menu bar.
- Исправлено пустое тело главного окна на этой macOS-сборке: при `NavigationSplitView` accessibility-дерево было полным, но контент визуально не появлялся. `HSplitView` отображает панель поиска, sidebar и разделы; отдельно проверено переключение на библиотеку и настройки. Логотип sidebar теперь читается через `Bundle.main.url(...)`, поскольку отдельный PNG в `Resources` не загружался через `Image("...")`.
- Нативный UI подключён к прежним Python сервисам через JSON Lines helper `study_agent.mac_bridge`; поддерживаются список папок/моделей, текстовый поиск и ответ Ollama по локальным выдержкам. Helper упаковывается PyInstaller в `Contents/Resources/Backend`.
- Настройки темы и доступности сохраняются в UserDefaults, выбранные каталоги — обычными bookmarks. App Sandbox выключен для локального PyInstaller helper; логика поиска и ответа осталась в Python, Qt UI не является зависимостью нативного `.app`.
- Создан `scripts/build_macos_native_app.sh`: релизный Xcode build, упаковка Python helper и локальная ad-hoc подпись в `~/Applications/Study Agent.app`. Минимум macOS 14, нужны Xcode и локальное Python-окружение.
- Релизная сборка в текущем окружении прошла, приложение установлено и запущено. SwiftUI-бинарник и PyInstaller helper собраны под архитектуру этого Mac (arm64); подпись проверена `codesign --verify --deep --strict`. Helper локально обработал команды списка источников и моделей Ollama.
- Локальный Git-репозиторий подключён к `gregkorneev-BMSTU/study-agent`; основная работа ведётся в `main`.
- Добавлены минимальный пакет `src/study_agent`, `pyproject.toml`, pytest, Ruff, CI для Python 3.12/3.13, `.gitignore`, `AGENTS.md` и Wiki.
- Реализован read-only `LocalFolderSource` для `.txt` и `.md`; корень передаётся параметром. Путь пользователя не вшит в исходники.
- `LocalFolderSource` теперь также перечисляет PDF и изображения. Извлекатель читает текстовый слой PDF напрямую, вызывает локальный Chandra HF OCR только для страниц с менее чем 32 буквенно-цифровыми символами, а изображения распознаёт целиком. Текстовый результат кэшируется по SHA-256 содержимого вне папки источника и Git; см. [инструкцию Chandra](chandra-ocr.md).
- Chandra установлена как необязательная группа `.[ocr]`, веса не упаковываются в репозиторий или приложение. macOS helper получает OCR при сборке из окружения с `.[packaging,ocr]`; PySide6 поиск использует тот же backend.
- Реализован PySide6 GUI: «Поиск», «Библиотека», «Настройки», добавление выбранных папок, настройка модели Ollama и пользовательские настройки темы/доступности. Токены и fallback описаны в [дизайн-системе](design-system.md).
- Добавлено нативное меню macOS: «Study Agent», «Файл», «Правка», «Вид», «Окно» и «Справка». Команды меню связаны с действующими сценариями; пункты темы/доступности и переходов синхронизированы с интерфейсом, стандартные действия редактирования работают с активным полем.
- Иконки навигации на macOS обновлены до SF Symbols (`magnifyingglass`, `books.vertical`, `gearshape`) с цветом, согласованным с активным состоянием и темой. Для иных платформ оставлен текстовый fallback.
- Работают локальный поиск по словам в `.txt`/`.md`, генерация ответа через Ollama loopback API и открытие источников из результатов. Настройки хранятся локально через `QSettings`.
- Автоматические проверки не требуют GUI-дисплея или установленной модели. Qt 6.12 не загрузил плагин `cocoa`; на Qt 6.10.3 `QApplication` и полный интерактивный запуск проверены. Для интерактивного QA использован установленный Cocoa-плагин PySide6 6.10.3 через `QT_QPA_PLATFORM_PLUGIN_PATH`, исходники проекта подключены через `PYTHONPATH=src`. Выбран диапазон PySide6-Essentials `>=6.10.3,<6.11`. Windows, пакетирование и качество на больших коллекциях не проверены.
- Для предоставленного автором каталога ранее собрана только локальная карта типов файлов и метаданных. Содержимое документов не читалось и индексация не запускалась; карта хранится локально вне Git.
- На машине автора подготовлен Python 3.12.15 и `.venv`; в этой сессии 21 не-Qt тест и `ruff check .` прошли. Полный pytest запуск прерван на `tests/test_switch.py`, потому что установленный Qt 6.10.3 platform-plugin loader не загружает `minimal`/`cocoa`; причина локализована в загрузке Qt plugin, а не в SwiftUI-проекте. Подробности прежнего визуального QA Qt-интерфейса — в [отчёте QA Liquid Glass](../artifacts/liquid-glass-qa/README.md).
- Интерфейс использует утверждённую фирменную цветовую систему для светлой и тёмной тем, тему Qt-системы, непрозрачные нейтральные поверхности, контрастные границы и семантические статусы поиска/Ollama. Сохранены настройки уменьшения прозрачности, повышенного контраста и уменьшения движения. Контрасты текстов и интерактивных элементов рассчитываются в `tests/test_theme.py`; Cocoa screenshots записаны в [отчёте цветовой системы](../artifacts/color-system-qa/README.md).
- Три переключателя настроек перерисованы единым векторным `AppleSwitch` с цветами светлой/тёмной темы, состояниями фокуса и отключения, кликом по подписи, клавиатурой и анимацией 170 мс. Ключи настроек и обработчик параметров сохранены. Покрыты Qt-тестами состояние доступности, Space, клики, размеры и Reduce Motion; визуальные кадры четырёх сочетаний темы/состояния находятся в [отчёте переключателя](../artifacts/switch-qa/README.md).
- Нативная Xcode-сборка — единственный поддерживаемый macOS `.app`; PySide6 остаётся источником для Windows/разработки. Ollama устанавливается отдельно.
- В SwiftUI настройках macOS нет отдельного переключателя уменьшения прозрачности; панель инструментов использует автоматический системный фон. PySide6 интерфейс не менялся.
- Нативный macOS UI полностью переключается между русским и английским через настройку языка; выбор сохраняется в `UserDefaults`, при первом запуске используется язык macOS, если он русский или английский, иначе — английский. Навигация, панели, меню, состояния поиска/Ollama, ошибки и подсказки переведены. SwiftUI передаёт выбранный язык локальному backend, и Ollama формирует ответ на выбранном языке. PySide6 интерфейс пока остаётся русскоязычным.
- В репозиторий добавлен предоставленный Apple icon kit (SVG, PNG, ICNS и исходные слои). Xcode использует иконки из `StudyAgent.xcassets` для приложения и About panel; боковая панель загружает `assets/StudyAgent_Apple_Icon_Kit/Master/AppIcon_1024.png`. В комплекте исходных иконок также сохранена menu bar графика.
- В About panel отображаются bundle icon, версия `1.0.0` (build 1) и `Developer: Gregory Korneev`; значения версии читаются из `Info.plist`, который создаётся из Xcode `MARKETING_VERSION`/`CURRENT_PROJECT_VERSION`.
- Проверена структура внешнего IU5Hub для будущего отдельного адаптера; его репозиторий не изменялся.
- Прочитано полное целевое описание пользователя: настольное приложение Windows/macOS, разделы «Поиск»/«Библиотека», автоматическая индексация после добавления папки, Chandra OCR, локальные эмбеддинги и Qwen/RAG, проверяемые источники, офлайн-работа, будущие MCP-инструменты.
- Wiki синхронизируется с требованием распространять приложение через GitHub независимо от локальных путей автора.

## Не готово

- Извлечение DOCX, инкрементальная индексация и постоянное хранилище.
- Постоянный индекс, инкрементальное обновление, локальные эмбеддинги и гибридный поиск.
- Извлечение DOCX, IU5HubSource, прогресс индексации, MCP-инструменты и Windows-установщик.
- Измерения точности/времени/памяти Chandra на русской печати, почерке, формулах и таблицах. Номер страницы хранится в извлечённом тексте, но пока не выделен в отдельное поле результата.
- Проверка качества/скорости Chandra для русских сканов, рукописей, формул и таблиц на Apple Silicon и Windows.
- Проверка лицензий остальных моделей и зависимостей для будущей дистрибуции; веса Chandra не включаются в сборку.
- Проверка чистой установки на Windows; кроссплатформенность пока не подтверждена.
- В этой сессии весь `pytest` остановился на `tests/test_switch.py`: текущий PySide6 plugin loader не загружает платформенный plugin (`Could not find the Qt platform plugin` / `shared library was not found`). Остальные 21 теста прошли при отдельном запуске; `ruff check .` прошёл.
- Проверено переключение разделов и тем, настройки уменьшенной прозрачности/повышенного контраста/уменьшения движения, остановка активного затухания и прокрутка при минимальном размере окна. Cocoa screenshot и raster timing выполнены; подробности и ограничения приведены в [отчёте QA Liquid Glass](../artifacts/liquid-glass-qa/README.md). VoiceOver и Windows UI Automation отдельно не проверялись.

## Ограничения и следующий этап

- Не читать/индексировать личную библиотеку, пока пользователь не выбрал источник в приложении или явно не запустил обработку.
- Не отправлять пользовательские материалы во внешние модели/API.
- Следующий технический этап: добавить постоянный индекс и обновление изменившихся файлов в выбранных папках; затем расширить интерфейс прогрессом и добавить DOCX. Пользовательские каталоги и абсолютные пути не использовать в тестах или публикуемых файлах.
- См. [дорожную карту](roadmap.md), [решения](decisions/README.md) и [архитектуру](architecture.md).
