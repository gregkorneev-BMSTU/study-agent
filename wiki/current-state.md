# Текущее состояние

Состояние на 2026-10-23. Целевая спецификация расширена до кроссплатформенного настольного приложения с локальным OCR, RAG и распространением через GitHub. Фактическая реализация пока остаётся начальным каркасом.

## Готово

- Локальный Git-репозиторий подключён к `gregkorneev-BMSTU/study-agent`; основная работа ведётся в `main`.
- Добавлены минимальный пакет `src/study_agent`, `pyproject.toml`, pytest, Ruff, CI для Python 3.12/3.13, `.gitignore`, `AGENTS.md` и Wiki.
- Реализован read-only `LocalFolderSource` для `.txt` и `.md`; корень передаётся параметром. Путь пользователя не вшит в исходники.
- Реализован PySide6 GUI: «Поиск», «Библиотека», «Настройки», glass-inspired оформление, добавление выбранных папок и настройка модели Ollama.
- Работают локальный поиск по словам в `.txt`/`.md`, генерация ответа через Ollama loopback API и открытие источников из результатов. Настройки хранятся локально через `QSettings`.
- Автоматические проверки не требуют GUI-дисплея или установленной модели. Offscreen-снимок окна удалось создать один раз; повторный запуск Qt в командной среде не нашёл платформенный плагин, поэтому обычный интерактивный старт приложения ещё нужно подтвердить в пользовательском сеансе. Windows, пакетирование и качество на больших коллекциях не проверены.
- Для предоставленного автором каталога ранее собрана только локальная карта типов файлов и метаданных. Содержимое документов не читалось и индексация не запускалась; карта хранится локально вне Git.
- На машине автора подготовлен Python 3.12.15 и `.venv`. Предыдущие локальные и CI проверки pytest/Ruff проходили; эта запись не утверждает, что проверки выполнялись при текущем обновлении Wiki.
- Проверена структура внешнего IU5Hub для будущего отдельного адаптера; его репозиторий не изменялся.
- Прочитано полное целевое описание пользователя: настольное приложение Windows/macOS, разделы «Поиск»/«Библиотека», автоматическая индексация после добавления папки, Chandra OCR, локальные эмбеддинги и Qwen/RAG, проверяемые источники, офлайн-работа, будущие MCP-инструменты.
- Wiki синхронизируется с требованием распространять приложение через GitHub независимо от локальных путей автора.

## Не готово

- Извлечение PDF/DOCX/изображений, OCR Chandra, инкрементальная индексация и постоянное хранилище.
- Постоянный индекс, инкрементальное обновление, локальные эмбеддинги и гибридный поиск.
- Извлечение PDF/DOCX, OCR Chandra, IU5HubSource, прогресс индексации, MCP-инструменты и установщики.
- Проверка качества/скорости Chandra для русских сканов, рукописей, формул и таблиц на Apple Silicon и Windows.
- Проверка лицензий весов и полного набора зависимостей для распространения.
- Проверка сборки и чистой установки на Windows; кроссплатформенность пока не подтверждена.

## Ограничения и следующий этап

- Не читать/индексировать личную библиотеку, пока пользователь не выбрал источник в приложении или явно не запустил обработку.
- Не отправлять пользовательские материалы во внешние модели/API.
- Следующий технический этап: добавить постоянный индекс и обновление изменившихся файлов в выбранных папках; затем расширить интерфейс прогрессом и добавить PDF. Пользовательские каталоги и абсолютные пути не использовать в тестах или публикуемых файлах.
