# Текущее состояние

Снимок на 2026-10-24. Последний опубликованный выпуск — **Study Agent v1 Beta 2** (`v1.0.0-beta.2`, macOS arm64). Основные функции Beta 2 уже выходят за рамки начального каркаса. Изменения Liquid Glass и Welcome Experience из [PR #7](https://github.com/gregkorneev-BMSTU/study-agent/pull/7) включены в `main`, но ещё не опубликованы в DMG Beta 2.

Собственный исходный код Study Agent распространяется под MIT License. Третьи стороны, модельные веса и иконографика не включаются в это заявление автоматически; см. [LICENSE](../LICENSE) и [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md). Сборочный процесс macOS копирует уведомления в приложение; Windows-дистрибутив и происхождение части графических ресурсов требуют дополнительной проверки.

## В Beta 2

- Нативное приложение SwiftUI/Xcode (deployment target macOS 14) с `HSplitView`, поиском, библиотекой, отдельным окном настроек, SF Symbols, системными меню и Menu Bar Extra.
- Общие Python-сервисы упакованы в PyInstaller helper и доступны SwiftUI через JSON Lines bridge. PySide6 UI — отдельный прототип/кандидат для будущей Windows-оболочки; Windows-сборка ещё не готова.
- Поиск по выбранным локальным TXT/Markdown, PDF и изображениям; извлечение PDF text layer; OCR Chandra предусмотрен при наличии runtime, но аудит текущей macOS-сборки не обнаружил пакет `chandra`, поэтому OCR в распространяемой `.app` не подтверждён; ответы локальной Ollama по найденным выдержкам. Полного постоянного индекса и RAG пока нет.
- SetupWizard проверяет систему, backend, Ollama и модели; позволяет перейти к установке Ollama, загрузить Qwen 3.5 4B через локальный API и отдельно установить Chandra OCR с прогрессом и отменой. Все загрузки начинаются только после действия пользователя; веса Chandra не включены в DMG.
- Настройки языка, темы и доступности хранятся локально. Пользовательские документы, индексы и модели не добавляются в Git.

## В `main`, ещё не включено в Beta 2

- Замена `HSplitView` на `NavigationSplitView`, проверенная в изолированной сборке на macOS 27; deployment target остаётся macOS 14.
- Три страницы Welcome Experience перед существующим SetupWizard; оба этапа показываются в одном sheet. Beta 1/2 с сохранённым `setup.completed.v1` не получают новое приветствие.
- Заголовки меню macOS обновляются по выбранному языку. Объектные `NSMenuItem.title` менялись в QA, но визуальное подтверждение и доступность меню ещё не получены: UI Automation продолжал сообщать английские подписи, а системный screenshot захватывал lock screen.
- Исправление CI для отсутствовавшей OCR-тесту зависимости `tqdm` включено в `main`. GitHub Actions на Python 3.12/3.13 прошёл: [run 40129447523](https://github.com/gregkorneev-BMSTU/study-agent/actions/runs/40129447523).

## Выпуск и проверка

- Beta 2: Xcode version 1.0.0 (build 2), ad-hoc DMG для macOS arm64. Проверки DMG и ограничения подписи описаны в [инструкции выпуска](macos-release.md) и [тестировании](testing.md). Developer ID-подписи и нотариализации нет.
- В PR #7 локальные Xcode Debug/Release сборки прошли на macOS 27 с deployment target macOS 14. `pytest --ignore=tests/test_switch.py` — 31 passed, Ruff прошёл. Полный локальный pytest исключал один Qt Cocoa-тест, который аварийно завершает Python в этой среде; полная pytest-матрица GitHub CI прошла.
- Welcome UI проверен в изолированной Release-копии на macOS 27: переходы, русский/английский текст и запуск диагностики. Скриншоты не удалось сохранить; VoiceOver, полный keyboard-only прогон и macOS 14/15 не проверялись.

## Ещё не реализовано или не подтверждено

- Постоянный индекс, инкрементальная индексация, эмбеддинги, гибридный семантический поиск и полноценный RAG с проверяемыми ссылками/страницами.
- DOCX, IU5HubSource, MCP-инструменты, прогресс полной индексации и Windows-установщик/проверенная Windows-сборка.
- Точность, скорость и память Chandra на русской печати, рукописи, формулах и таблицах на целевых компьютерах; OCR inference с реально скачанными весами в последнем QA.
- Чистая установка и Gatekeeper на другом Mac, нотариализация, VoiceOver и физическая проверка доступности на минимальной поддерживаемой macOS.

См. [архитектуру](architecture.md), [дорожную карту](roadmap.md), [дизайн-систему](design-system.md) и [план проверок](testing.md).

В PR #9 (`feature/macos-glass-appearance`) исправляется настройка Liquid Glass: ошибочный ползунок прозрачности всего окна удаляется. В настройках остаётся описание системного материала, приоритет Reduce Transparency и переход в System Settings. Публичные Apple API не предоставляют приложению числовой per-app уровень Liquid Glass; подробности — в [отчёте QA](../artifacts/macos-glass-appearance-qa/README.md).
