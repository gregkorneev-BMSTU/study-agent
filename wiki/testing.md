# Тестирование

## Автоматические проверки

Минимальная CI матрица запускает Python 3.12 и 3.13, `pytest` и `ruff check .`. Она не скачивает модели и не требует Ollama. Локально запустите те же команды из README после установки `.[dev]`.

На текущем этапе единственный синтетический smoke-тест подтверждает импорт пакета и определённую версию. Нет функциональности поиска, которую следовало бы тестировать.

## Будущая стратегия

- Быстрые unit-тесты для извлечения текста, нормализации метаданных, разбиения и маршрутизации без внешних моделей.
- Лёгкие фикстуры синтетических документов в tests; не хранить пользовательские учебные материалы в Git.
- Отдельная маркировка/команда для интеграционных тестов с реальными локальными моделями и файловыми индексами.
- Проверять воспроизводимость ссылок на источники, повторную индексацию, удаление источника и обработку недоступных путей.
- Не требовать сетевого доступа или Ollama в стандартном CI.

## Результат первого запуска

Проверки 2026-10-22: smoke-import пакета и версии прошёл на системном Python 3.9.6; `compileall` и `git diff --check` прошли. `pytest --version` и `ruff --version` завершились `No module named pytest` / `No module named ruff`; тесты pytest и линтинг поэтому не выполнены. Python 3.12+ также отсутствует. После настройки отдельного актуального Python нужно выполнить `python -m pip install -e '.[dev]'`, `pytest` и `ruff check .`.
