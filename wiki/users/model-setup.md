# Локальная языковая модель

← [Пользователю](README.md) · [Wiki](../README.md)

Study Agent использует локальную модель Ollama, чтобы составлять ответы по найденным фрагментам. Поиск по материалам работает и без языковой модели, но без неё приложение не генерирует ответ.

## Установка через приложение

1. При первом запуске следуйте подсказкам мастера Study Agent.
2. Установите Ollama, если мастер сообщает, что она отсутствует.
3. Подтвердите загрузку предложенной модели. Загрузка занимает время и требует свободного места на диске.
4. В настройках обновите список моделей и выберите установленную модель.

Модель можно изменить позднее в настройках. Установка и генерация выполняются локально; сами учебные материалы не передаются в облачную модель.

Если мастер не завершил установку, откройте [официальную страницу Ollama](https://ollama.com/download), установите Ollama, а затем выполните в Terminal:

```sh
ollama pull qwen3.5:4b
```

Вернитесь в Study Agent, обновите список моделей и выберите `qwen3.5:4b`. Дополнительные команды и сведения для разработчиков находятся в [техническом руководстве](../development/model-setup.md).

Для настройки распознавания сканов см. [Chandra OCR](chandra-ocr.md).
