# Начало работы

← [Пользователю](README.md) · [Wiki](../README.md)

Актуальная сборка Beta 6.1 предназначена для macOS 14+ на Apple Silicon. Скачать её можно из раздела [Скачать и установить](../../README.md#скачать-и-установить). Проверенной сборки для Windows пока нет.

## Первый запуск

1. Откройте DMG и перетащите **Study Agent.app** в **Applications**.
2. Запустите приложение и пройдите знакомство.
3. Мастер проверит необходимые компоненты. Установка Ollama, языковой модели и Chandra начинается только после вашего действия.
4. Откройте **Библиотека** и добавьте папку с материалами. Дождитесь окончания индексации.
5. Перейдите в **Поиск**, введите вопрос или тему и нажмите **Спросить**.

DMG пока не нотариализован Apple. Если macOS не открывает приложение, в Finder нажмите приложение правой кнопкой мыши, выберите «Открыть» и подтвердите запуск в системном диалоге.

## Модель и распознавание

Для ответа по найденным материалам установите Ollama и выберите локальную языковую модель. Поиск по тексту доступен и без неё. Для сканов, рукописных пометок и изображений отдельно установите Chandra OCR.
