# Пользователю

← [Wiki](../README.md)

Короткий маршрут от установки до поиска по своим материалам:

1. Скачайте актуальную сборку по ссылке из [README проекта](../../README.md) и пройдите [первый запуск](onboarding.md).
2. Проверьте [настройку локальной модели](model-setup.md), если хотите получать ответы, а не только результаты поиска.
3. Добавьте нужные папки в Библиотеку. Файлы индексируются на этом компьютере.
4. Для сканов, рукописных пометок и изображений установите Chandra по [руководству OCR](chandra-ocr.md).

## Если что-то не работает

- Загляните в [release notes текущей версии](../releases/README.md), чтобы проверить ограничения сборки.
- Проверьте, что нужная модель установлена и выбрана в настройках.
- В Wiki OCR приведены условия установки Chandra и известные ограничения распознавания.
- [Карта всей Wiki](../README.md) поможет перейти к технической документации.
