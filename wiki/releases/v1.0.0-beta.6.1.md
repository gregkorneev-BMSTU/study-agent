# Study Agent v1 Beta 6.1

← [Выпуски](README.md) · [Wiki](../README.md)


> Предварительная сборка для macOS 14+ на Apple Silicon (arm64). Подписана ad-hoc, без нотариализации Apple; Gatekeeper может блокировать запуск.

## Русский

Beta 6.1 исправляет выбор OCR в Beta 6. Прежний тег и образ Beta 6 сохранены: обновление опубликовано отдельно, чтобы исходники соответствовали сборке.

### Что изменилось

- Chandra запускается для **каждой страницы PDF**, даже когда в ней есть печатный текстовый слой. Читаемый цифровой текст и результат OCR сохраняются с номером страницы; рукописная пометка не теряется из-за печатного заголовка.
- Встроенные изображения в тексте и таблицах DOCX тоже распознаются, а обычный текст DOCX сохраняется.
- Локальные изображения, на которые ссылается Markdown внутри подключённой папки, индексируются как отдельные источники. Файлы вне выбранной папки и внешние URL не загружаются.
- При «Проверить изменения» существующие PDF и DOCX повторно обрабатываются по новой версии извлечения; старый PDF-кэш не препятствует запуску OCR. При ошибке OCR доступный печатный текст остаётся в поиске и показывается предупреждение.

### Проверка и ограничения

- Python: 226 тестов прошли, 10 opt-in тестов живой модели пропущены; Ruff прошёл.
- Chandra на первой странице проверенного PDF вернула 1478 символов, включая 543 кириллические буквы. Это подтверждает запуск модели, но не измеряет точность распознавания всех страниц.
- Упакованный backend отдельно проиндексировал изображение страницы, одностраничный PDF с текстовым слоем и DOCX с печатным абзацем и встроенным изображением: во всех случаях OCR-фрагменты сохранились без ошибок. DMG прошёл `hdiutil verify`, копия приложения — строгую проверку ad-hoc подписи; приложение и backend имеют архитектуру arm64, номер сборки — 7.
- OCR каждой страницы увеличивает время индексации и нагрузку на Mac. Веса Chandra не входят в DMG и не скачиваются автоматически; их нужно установить отдельно в настройках.
- Графический запуск и качество распознавания всех страниц документа не проверялись.

### Установка

Откройте DMG, перетащите `Study Agent.app` в `Applications`. После обновления откройте Библиотеку и выберите «Проверить изменения» для подключённой папки, чтобы пересчитать старые PDF и DOCX. Установка поверх Beta 6 не удаляет ваши документы, индекс и веса Chandra.

## English

Beta 6.1 fixes OCR selection in Beta 6. The original Beta 6 tag and DMG remain intact; this update has a separate tag so its source matches the build.

### Changes

- Chandra runs on **every PDF page**, even when it has a printed text layer. Readable digital text and OCR output retain the page number, so printed headings do not prevent handwritten notes from being searched.
- Embedded images in DOCX paragraphs and tables are recognized while ordinary DOCX text is preserved.
- Local images linked from Markdown inside the connected folder are indexed as separate sources. Files outside the selected folder and external URLs are not fetched.
- **Check for Changes** reprocesses existing PDF and DOCX files with the new extraction version. The old PDF cache cannot bypass OCR. If OCR fails, available printed text remains searchable and a warning is shown.

### Testing and limitations

- Python: 226 passed, 10 opt-in live-model tests skipped; Ruff passed.
- Chandra returned 1,478 characters, including 543 Cyrillic letters, from the first page of the checked PDF. This confirms model execution, not recognition accuracy across all pages.
- The packaged backend separately indexed a page image, a one-page PDF with a text layer, and a DOCX with printed text and an embedded image. OCR chunks were saved without errors in each case. `hdiutil verify` validated the DMG, a copied app passed strict ad-hoc signature verification, both binaries are arm64, and the build number is 7.
- OCR on every page increases indexing time and Mac resource use. Chandra weights are not bundled or downloaded automatically; install them separately in Settings.
- GUI launch and recognition quality across every page of the document were not checked.

### Install

Open the DMG and drag `Study Agent.app` to `Applications`. After updating, use **Check for Changes** on a connected folder to reprocess existing PDF and DOCX files. Installing over Beta 6 does not remove documents, the index, or Chandra weights.
