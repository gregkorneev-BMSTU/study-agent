# Study Agent v1 Beta 5

> Pre-release for testing. Requires macOS 14 or later on Apple Silicon (arm64). This DMG is ad-hoc signed and has not been notarized by Apple; Gatekeeper may block it.

## Русский

Beta 5 включает обновлённый `main` после Beta 4 и исправляет локальный вызов Chandra OCR.

### Новое

- Параметры генерации Chandra передаются через `InferenceManager.generate()`, совместимо с установленным `chandra-ocr 0.2.x`.
- Исправленный Python backend выполнил локальное распознавание всех пяти страниц PDF. Результат был проверен в окружении разработки.
- Диагностика упакованного backend подтверждает наличие OCR runtime. Веса Chandra не включены в DMG; их можно отдельно загрузить в «Настройки → Компоненты и диагностика».

### Проверка и ограничения

- `ruff check .` прошёл; Xcode Release и PyInstaller backend arm64 собраны успешно. `hdiutil verify` подтвердил целостность DMG.
- OCR inference проверен в Python-окружении разработки; inference внутри упакованного `.app` отдельно не запускался.
- PDF с достаточным цифровым текстовым слоем извлекается напрямую. Chandra автоматически запускается для страниц, где найдено менее 32 буквенно-цифровых символов; изображения всегда проходят OCR.
- `pytest` для этой сборки не запускался. Семантические embeddings и полноценный RAG не входят в эту версию.

### Установка

Откройте DMG, перетащите `Study Agent.app` в `Applications`, затем запустите. Если Gatekeeper заблокирует приложение, используйте системное действие macOS для открытия загруженного ad-hoc приложения. Выпуск предназначен для macOS 14+ на Apple Silicon; он не имеет Developer ID и не нотариализован Apple.

Артефакт `StudyAgent-v1.0.0-beta.5-macos-arm64.dmg`: 233,890,933 байта. `hdiutil verify` подтвердил целостность. SHA-256: `aad616730d26f2742ecf2deac6c5117d6cfb6f323251dfa240612284de84ba39`.

## English

Beta 5 includes the current `main` after Beta 4 and fixes the local Chandra OCR call.

### What’s new

- Chandra generation options are now passed through `InferenceManager.generate()`, compatible with installed `chandra-ocr 0.2.x`.
- The fixed Python backend completed local OCR on all five pages of a PDF. The output was checked in the development environment.
- Diagnostics in the bundled backend confirm the OCR runtime is present. Chandra weights are not included in the DMG; they can be downloaded separately in **Settings → Components & Diagnostics**.

### Testing and limitations

- `ruff check .` passed; the Xcode Release app and PyInstaller arm64 backend built successfully. `hdiutil verify` confirmed the DMG is valid.
- OCR inference was verified in the Python development environment; inference inside the packaged `.app` was not separately run.
- PDFs with sufficient digital text are extracted directly. Chandra is automatically used on pages with fewer than 32 alphanumeric characters; images always use OCR.
- `pytest` was not run for this build. Semantic embeddings and full RAG are not included.

### Install

Open the DMG, drag `Study Agent.app` to `Applications`, and launch it. If Gatekeeper blocks the app, use macOS’s system action for opening a downloaded ad-hoc app. This release requires macOS 14 or later on Apple Silicon; it has no Developer ID signature and has not been notarized by Apple.

The `StudyAgent-v1.0.0-beta.5-macos-arm64.dmg` artifact is 233,890,933 bytes. `hdiutil verify` confirmed its integrity. SHA-256: `aad616730d26f2742ecf2deac6c5117d6cfb6f323251dfa240612284de84ba39`.
