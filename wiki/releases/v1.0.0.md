# Study Agent v1.0.0

← [Выпуски](README.md) · [Wiki](../README.md)

> Первый стабильный выпуск Study Agent для macOS 14+ на Apple Silicon (arm64). Номер версии приложения — 1.0.0, номер сборки — 8. Образ подписан ad-hoc, Apple не нотариализовал его; Gatekeeper может блокировать запуск.

## Русский

Study Agent помогает искать в подключённых учебных материалах и получать ответы на основе найденных фрагментов. Документы, индекс и генерация ответов остаются на компьютере пользователя.

### Возможности

- Поиск по PDF, DOCX, Markdown, текстовым файлам и изображениям в выбранных папках.
- Лексический, семантический и гибридный поиск с локальными эмбеддингами.
- Ответы локальной модели Ollama с проверяемыми источниками и страницами PDF, когда они доступны.
- Chandra OCR для каждой страницы PDF, встроенных изображений DOCX и локальных изображений, указанных в Markdown. Печатный текст сохраняется рядом с результатом OCR.
- Нативный интерфейс SwiftUI на русском и английском, светлая и тёмная темы, мастер первого запуска и локальная библиотека.

### Установка и ограничения

Скачайте `StudyAgent-v1.0.0-macos-arm64.dmg`, откройте его и перетащите **Study Agent.app** в **Applications**. При обновлении выберите «Проверить изменения» для подключённых папок, чтобы пересчитать документы с актуальными правилами извлечения. Документы, индекс и веса Chandra хранятся отдельно от приложения.

Этот DMG подписан ad-hoc и не нотариализован Apple. На некоторых Mac Gatekeeper может показать предупреждение или заблокировать запуск; Developer ID-подпись и нотариализация для этого выпуска недоступны. Приложение предназначено для macOS 14+ на Apple Silicon. Для OCR нужно отдельно установить веса Chandra из настроек; веса не входят в DMG и не скачиваются автоматически. Для генерации ответов нужна локально установленная и запущенная Ollama с моделью.

## English

Study Agent searches user-selected study materials and answers questions using retrieved passages. Documents, the index, and answer generation stay on the user's Mac.

### Features

- Search PDF, DOCX, Markdown, text files, and images in selected folders.
- Lexical, semantic, and hybrid search with local embeddings.
- Answers from a local Ollama model, with verifiable sources and PDF pages when available.
- Chandra OCR on every PDF page, embedded DOCX image, and local image referenced by Markdown. Printed text is preserved alongside OCR output.
- Native SwiftUI interface in Russian and English, light and dark appearances, first-run setup, and a local library.

### Install and limitations

Download `StudyAgent-v1.0.0-macos-arm64.dmg`, open it, and drag **Study Agent.app** to **Applications**. After updating, choose **Check for Changes** for connected folders to reprocess documents with the current extraction rules. Documents, the index, and Chandra weights are stored separately from the app.

This DMG is ad-hoc signed and is not notarized by Apple. Gatekeeper may warn about or block the app on some Macs; Developer ID signing and notarization are unavailable for this release. The app targets macOS 14+ on Apple Silicon. Chandra weights must be installed separately from Settings; they are not included in the DMG or downloaded automatically. Answer generation requires a locally installed and running Ollama model.
