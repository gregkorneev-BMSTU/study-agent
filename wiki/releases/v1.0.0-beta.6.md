# Study Agent v1 Beta 6

← [Выпуски](README.md) · [Wiki](../README.md)


> Предварительный выпуск для тестирования на macOS 14+ с Apple Silicon (arm64). DMG подписан ad-hoc и не нотариализован Apple; Gatekeeper может блокировать запуск.

## Русский

Beta 6 включает изменения `main` после слияния [PR #14](https://github.com/gregkorneev-BMSTU/study-agent/pull/14).

### Новое

- Локальные эмбеддинги, семантический и гибридный поиск по подключённым материалам. Для поиска по смыслу нужно выбрать установленную embedding-модель и подготовить векторный индекс.
- Ответы локальной модели с проверяемыми ссылками на найденные источники. Ответы с неизвестными ссылками или абзацами без ссылок, в том числе короткими, отклоняются; найденные фрагменты остаются доступны.
- Карточки источников с совпавшими фрагментами и исходным текстом. Markdown и LaTeX отображаются локально без CDN.
- Встроенный Chandra OCR runtime для сканов и изображений. Веса Chandra загружаются отдельно и не входят в DMG.

### Проверка и ограничения

- Полный локальный Python-набор: **221 passed, 10 skipped** (пропущены opt-in проверки живой модели); Ruff прошёл. Все три проверки PR #14, включая macOS client, прошли.
- PyInstaller backend и Xcode Release arm64 собраны. `hdiutil verify` подтвердил целостность DMG; копия приложения в `/tmp` прошла `codesign --verify --deep --strict`.
- Упакованный helper ответил на `diagnose_backend`: backend, PDF и OCR runtime доступны. Состояние OCR-весов `installed` относится только к Mac, на котором проводилась проверка.
- Живой поиск/RAG, OCR inference и графический запуск именно из этого DMG не проверялись. Качество ответов и распознавания на пользовательских документах не подтверждено.

### Установка

Откройте DMG и перетащите `Study Agent.app` в `Applications`. При блокировке Gatekeeper используйте системное действие macOS для открытия приложения. Для смыслового поиска нужна локальная Ollama с установленной embedding-моделью; модели не входят в образ.

Файл: `StudyAgent-v1.0.0-beta.6-macos-arm64.dmg` (236 474 122 байта). SHA-256: `8d6bd4ca72e5d7a4aa69e97b237ebdedfcf69f5be836648d8dc9f98dd670f48a`.

## English

Beta 6 includes the changes merged into `main` in [PR #14](https://github.com/gregkorneev-BMSTU/study-agent/pull/14).

### What's new

- Local embeddings and semantic and hybrid search across connected materials. Semantic search requires an installed embedding model and a prepared vector index.
- Local model answers with validated citations to retrieved sources. Answers with unknown citations or uncited paragraphs, including short statements, are rejected while search results remain available.
- Source cards with matching excerpts and original text. Markdown and LaTeX render locally without a CDN.
- Bundled Chandra OCR runtime for scans and images. Chandra weights are downloaded separately and are not included in the DMG.

### Testing and limitations

- Local Python suite: **221 passed, 10 skipped** (opt-in live-model tests); Ruff passed. All three PR #14 checks passed, including the macOS client build.
- The PyInstaller backend and Xcode Release arm64 app built successfully. `hdiutil verify` validated the DMG; a copy of the app in `/tmp` passed `codesign --verify --deep --strict`.
- The packaged helper returned healthy backend, PDF and OCR runtime diagnostics. The `installed` OCR-weight status applies only to the test Mac.
- Live search/RAG, OCR inference, and launching the GUI from this specific DMG were not tested. Answer and OCR quality on user documents are unverified.

### Install

Open the DMG and drag `Study Agent.app` to `Applications`. If Gatekeeper blocks it, use macOS's system action to open the app. Semantic search requires local Ollama with an installed embedding model; models are not bundled.

Artifact: `StudyAgent-v1.0.0-beta.6-macos-arm64.dmg` (236,474,122 bytes). SHA-256: `8d6bd4ca72e5d7a4aa69e97b237ebdedfcf69f5be836648d8dc9f98dd670f48a`.
