# Study Agent v1 Beta 6 — локальная сборка

Beta 6 собрана из `main` после слияния PR #14 (`eae9884`). Образ находится только локально; GitHub Release и тег не создавались.

## Изменения

- Локальные эмбеддинги, семантический и гибридный поиск по подключённым материалам.
- Ответы локальной модели с проверяемыми ссылками на найденные источники. Короткие утверждения без ссылки также отклоняются.
- Обновлённые карточки источников и отображение Markdown/LaTeX без внешнего CDN.

## Проверка

- Python: 221 тест прошёл, 10 opt-in тестов живой модели пропущены; Ruff прошёл.
- PyInstaller backend и Xcode Release arm64 собраны. DMG прошёл `hdiutil verify`; приложение, скопированное в `/tmp`, прошло `codesign --verify --deep --strict`.
- Упакованный helper ответил на `diagnose_backend`: backend, PDF и OCR runtime доступны. Состояние OCR-весов `installed` относится к текущему Mac; веса в образ не включены.
- Живой поиск/RAG, OCR inference и графический запуск именно из этого образа не проверялись. Сборка подписана ad-hoc и не нотариализована; требуется macOS 14+ на Apple Silicon.
