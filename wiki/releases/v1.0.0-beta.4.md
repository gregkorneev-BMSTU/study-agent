# Study Agent v1 Beta 4

> Pre-release for testing. Requires macOS 14 or later on Apple Silicon (arm64). This DMG is ad-hoc signed and has not been notarized by Apple; Gatekeeper may block it.

## Русский

Beta 4 собирает изменения, вошедшие в `main` после Beta 3.

### Новое

- Постоянный локальный SQLite-индекс и инкрементальная индексация TXT, Markdown, PDF и DOCX. При повторной проверке неизменённые документы не извлекаются заново; изменённые обновляются, удалённые убираются из индекса.
- Извлечение содержимого DOCX с сохранением порядка текста и заголовков разделов.
- Исправлена упаковка native-библиотек `torchvision` во встроенном backend, необходимая OCR runtime.
- Библиотека macOS показывает реальные счётчики SQLite, очередь, прогресс индексации, последнюю успешную синхронизацию, ошибки и предупреждения документов. Доступны отмена, повтор и проверка изменений.
- Ошибки документов восстанавливаются из backend после перезапуска. Интерфейс отделяет технический код от понятного описания.
- Поздние события прогресса не меняют состояние уже отменяемой операции.
- Ответ Ollama показывает те же проверяемые фрагменты, которые переданы модели, со страницами PDF и заголовками DOCX, когда они доступны.

### Проверка и ограничения

- Python backend E2E проверен на временной папке с TXT, текстовым PDF и DOCX, включая изменение файлов и удаление документа.
- Модель Chandra и её веса не входят в DMG. OCR inference на сканах с установленными весами для этого выпуска не подтверждён.
- Для PDF показываются страницы из найденных фрагментов и открывается исходный файл системным приложением. Переход к указанной странице не реализован.
- Семантические embeddings и полноценный RAG не входят в эту версию. Windows-клиент в этом macOS-релизе не поставляется.
- Визуально проверены светлая и тёмная темы; сохранённые предупреждения отображаются в библиотеке. Малое окно, VoiceOver и macOS 14 не проверялись. Живые ошибки и отмена в UI не были полностью проверены из-за сбоя автоматизации кликов; состояние отмены проверено регрессионным Swift harness.
- `.venv/bin/python -m pytest -q --ignore=tests/test_switch.py`: 71 passed. Полный локальный `pytest` аварийно завершился при создании Qt Cocoa `QApplication` в `tests/test_switch.py`. `ruff check .`, Swift queue/DTO harness и Xcode Debug/Release сборки прошли. GitHub Actions Python 3.12/3.13 и macOS client прошли.

## English

Beta 4 includes the changes merged into `main` after Beta 3.

### What’s new

- Persistent local SQLite index and incremental indexing for TXT, Markdown, PDF, and DOCX. Unchanged documents are not extracted again during a check; changed documents are refreshed and deleted documents are removed from the index.
- DOCX extraction preserves text order and section headings.
- Fixed packaging of native `torchvision` libraries required by the bundled OCR runtime.
- The macOS Library shows SQLite-backed counts, the indexing queue and progress, last successful sync, document errors, and warnings. It supports cancellation, retry, and change checks.
- Document issues are restored from the backend after app relaunch. The interface keeps technical error codes separate from user-facing descriptions.
- Late progress events no longer change an operation that is being cancelled.
- Ollama answers show the same verifiable passages sent to the model, with PDF pages and DOCX headings when available.

### Testing and limitations

- The production Python backend was exercised on a temporary folder containing TXT, a text PDF, and DOCX files, including file changes and document deletion.
- Chandra and its model weights are not included in the DMG. OCR inference on scanned documents with installed weights is not confirmed for this release.
- PDF results show page references from retrieved passages and open the original file in the system app. Navigating directly to the cited page is not implemented.
- Semantic embeddings and full RAG are not included. This macOS release does not ship a Windows client.
- Light and dark appearances were visually checked; saved warnings appear in Library. A narrow window, VoiceOver, and macOS 14 were not checked. Live UI error and cancellation interactions were not fully verified because UI click automation failed; cancellation state was covered by the Swift regression harness.
- `.venv/bin/python -m pytest -q --ignore=tests/test_switch.py`: 71 passed. The full local `pytest` run aborted while creating the Cocoa `QApplication` in `tests/test_switch.py`. `ruff check .`, the Swift queue/DTO harness, and Xcode Debug/Release builds passed. GitHub Actions passed for Python 3.12/3.13 and the macOS client.

### Install

Open the DMG, drag `Study Agent.app` to `Applications`, and launch it. This release requires macOS 14 or later on Apple Silicon. It is ad-hoc signed, has no Developer ID signature, and has not been notarized by Apple.
