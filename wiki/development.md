# Разработка и Git

## Codex

Главный агент работает как Orchestrator: изучает Wiki, назначает независимые задачи, интегрирует изменения, запускает проверки и обновляет документацию. Роли и правила описаны в корневом `AGENTS.md`. Субагенты нужны только для независимых работ; максимум три одновременно. Они не меняют одни файлы без координации и не коммитят/push. Используйте возможности субагентов, реально предоставленные сессией; `AGENTS.md` сам по себе не запускает агентов.

Постоянные проектные правила и актуальная политика Git находятся в корневом `AGENTS.md`; эта страница описывает общий процесс и не фиксирует возможности отдельной сессии.

## Git

- Вся текущая разработка ведётся непосредственно в `main` по указанию пользователя от 2026-10-22.
- Не создавайте `beta` или другие рабочие ветки без нового указания пользователя.
- Коммитите логически законченные, проверенные изменения с соответствующей Wiki.
- Перед коммитом просмотрите `git diff`, `git status` и точный список staging-файлов. Не включайте `.env`, пользовательские документы, модели, базы/индексы и кэши.
- Публикуйте проверенные изменения непосредственно в `main`, если `origin` и аутентификация рабочие. Проверяйте push по результату Git. Не force push.
- Любой новый режим ветвления или отдельный процесс релизов требует явного указания пользователя.
- В исходном `iu5hub` ничего не менять.

## Текущая работа SA-03

По указанию пользователя от 2026-10-26 SA-03 ведётся в `feature/sa-03-rag` от обновлённой `main`. На текущем этапе разрешены только локальные коммиты; push, PR и merge отложены до нового указания пользователя. Эта инструкция имеет приоритет над прежним правилом прямой публикации в `main`.
