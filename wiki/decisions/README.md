# Решения и нерешённые вопросы

## Зафиксированные ограничения

- Python — основной язык; приложение и LLM должны работать локально по умолчанию.
- IU5Hub интегрируется через отдельный адаптер и не изменяется.
- Стандартный тестовый цикл не скачивает модели и не требует Ollama.
- Начальное окружение проекта требует Python 3.12+; системный Python на машине автора 3.9.6.
- `main` стабилен, обычная разработка — в `beta`; публикация стабильного релиза требует разрешения.

## Открытые вопросы — решений пока нет

1. UI-фреймворк: PySide6, React + локальный Python API или другой вариант.
2. LLM и квантование: Qwen3 4B — гипотеза для benchmark; сравнение с 8B и иными локальными вариантами.
3. Модель эмбеддингов и её русскоязычное качество.
4. Гибридный поиск: лексический/векторный ранжировщик, объединение и фильтры.
5. Сканированные PDF и OCR.
6. Нужен ли LangGraph; структура агентного workflow.
7. Формат, путь, резервное копирование и политика очистки исходников/индекса.
8. Точный API/способ доступа IU5Hub, размерные лимиты, повторное использование кеша и условия загрузки.

Не считать эти решения принятыми, пока не добавлено отдельное обоснование и результат измерений.
