# Contributing to Study Agent

Study Agent is developed as an open-source project. Bug fixes, documentation improvements, and feature proposals are welcome.

## Workflow

1. Create a branch for your change and open a Pull Request against `main`.
2. Keep the change focused and describe its user-facing impact.
3. Run the relevant checks (`pytest` and `ruff check .` for Python changes) and include the results in the Pull Request.
4. Changes are reviewed before they are merged.
